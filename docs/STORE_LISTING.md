# Microsoft Store listing

The current en-US listing source is store/listing.en-us.json. It covers the implemented integrated tools, Brainiac Edge, local OCR, capture/recording and teleprompter. No cloud, scheduled workflow or unsupported format is advertised.

Real screenshots and rendering evidence are generated by the executable Windows test harness with --store-review under artifacts/store/screenshots. The screenshots show actual views from an isolated profile. They are not mockups. render-density-* files are synthetic rendering checks; use the light/dark/tool screenshots as listing candidates after visual review.

The assigned identity and public GitHub support/privacy URLs are configured in store/identity.json. A separate support email can be supplied optionally. scripts/prepare-store-content.ps1 creates final listing/contact files in artifacts/store/submission. store/privacy.html is a hostable policy draft; it has not been deployed. Listing drafts alone are not a live Store listing.

The account owner must finalize pricing, territories, age ratings, compliance answers and publication timing. See store/CERTIFICATION-NOTES.md and store/ACCEPTANCE.md.
