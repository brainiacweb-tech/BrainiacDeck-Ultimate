# Offline help
## Start
Choose a tool from the left navigation. Ctrl+Shift+Space opens Command Center when registration succeeds. Settings saves light/dark appearance and window behavior. Tray double-click restores the main window. The close button exits after confirmation when enabled.

## Converter
Drop supported files, select a compatible output, choose an existing output folder, then run the queue. Existing files get a numbered alternative name. Email preset uses JPEG quality 75 and max width 1600. A saved preset stores one reusable configuration. Review per-file results and sizes. Cancellation takes effect between codec phases; it cannot interrupt every native codec call. GIF and TIFF inputs export their first frame only. Transparent JPEG output uses white.

Combine images, text, Markdown source and PDFs into a PDF. Text wrapping is basic; Markdown is source text, not rich rendering. PDF-only queues support page reversal and 90-degree rotation. Separate page tools accept selections such as 1,3-5,2, export selected/reordered pages or split all pages. Signed/encrypted/malformed PDFs may fail; originals remain untouched. Compression is not advertised.

## Clipboard Shelf
Manual Add reads the current clipboard once. Monitoring is off until consent is checked and stops when unchecked or the shelf closes. Search, select, pin, reorder, transform text, copy, save TXT, or open text in the teleprompter. Persistence is off by default. Enable Save shelf across restarts to protect and restore items with your Windows account; monitoring still requires fresh session consent. Disabling persistence deletes the saved shelf. Exclusion words apply to text; pause before copying secrets.

## Teleprompter
Open Teleprompter to show an independent compact always-on-top overlay beneath the webcam. It remains visible while the main app minimizes. Edit script opens a real editor with new/import/paste, a searchable saved library and TXT export. Save to library protects the script using your Windows account; Use script applies edits without saving them. Play/pause scrolls the actual text viewport. Ctrl+Alt+P plays/pauses, Ctrl+Alt+R restarts, and Ctrl+Alt+X dismisses when registration succeeds; conflicts are reported. Drag the label, double-click to snap to top centre, and resize from the lower-right grip. Additional controls appear on hover. Settings adjusts font, opacity, width, speed, mirroring and target monitor. Display settings and geometry restore next time. Optional offline voice follow requires an installed Windows speech language and explicit microphone consent each session; no audio is saved. Windows desktop microphone access may need enabling in Windows Settings. Stop voice follow or close the overlay to release the microphone. Capture exclusion is a Windows request and must be tested with your recorder; it is not a promise of invisibility.

## File toolkit
Select files, calculate hashes, optionally compare an expected hash, inspect metadata or export results. Preview numbered renames before applying; collisions are rejected and the last operation can be undone. Duplicate scans hash then compare bytes and never delete anything. ZIP extraction creates a new folder and rejects traversal, symbolic links, excessive entries and expansion beyond the size limit. Password-protected ZIPs are not supported.

## Workflows
Choose separate input/output folders, an extension filter and Copy/SHA-256/ZIP steps. Each step reads the original selected source set. Dry-run, review paths, then confirm execution. Results go into a fresh run directory with a log. Cancellation leaves partial results for inspection. No folder watcher or scheduler runs in the background.

## Capture
Choose Primary display, All displays, Select region or Foreground window and a countdown. App panels hide while capturing the desktop. For foreground capture, focus the desired window during the countdown. Region selection uses a desktop overlay; Escape cancels. Open/drop an image to edit an existing file. Choose Crop, drag a rectangle and Apply crop; arrow, rectangle, highlight, opaque redaction and text apply on drag. Color, stroke and text size controls appear for relevant tools. View zoom changes only the editor view. Undo/reset retains original pixels in memory; redaction exports opaque black pixels. Choose Original, 720p, 1080p, square or portrait output and fit/padding or fill/center-crop. Preview export before PNG/JPEG/PDF export, clipboard copy or shelf handoff. Upscaling cannot restore missing source detail; social platforms may recompress uploads. Use OCR to Clipboard Shelf to pin the edited capture, recognize it with installed local Windows OCR, and pass recognized text through Shelf privacy filters.

For video, choose the Recording tab, output size and target frame rate, then Start recording and select a new MP4 filename. Use the floating toolbar to pause/resume or Stop and save. Recording is video-only: no microphone or system audio. Windows is asked to exclude the toolbar from capture, but verify this on your device. Recording stops after two hours; actual frame rate depends on capture/encoding load. Edit the last recording or open a local MP4. The editor supports playback, start/end trim in seconds, a crop selected on the first frame, and centered zoom from 1x to 4x. Export creates a separate H.264 MP4 and does not include imported audio. Existing video files are never overwritten. Cancel removes the unfinished export after the current native codec call returns. During recording/export a temporary .partial.mp4 exists beside the selected output; a forced process exit can leave it behind. Protected desktop content may be blank. Editing supports compatible Windows codecs and frames up to 3840 pixels per side; variable presentation dimensions are rejected.

## Workspaces and privacy
Save collections of tools; safe imported configurations do not execute on import. Privacy Center shows/clears activity and removes saved workspace/workflow/preset/favorite configurations. User-exported files remain yours to manage.

## Troubleshooting
Storage errors are displayed without silently resetting data. Check local profile folder permissions. Shortcut conflicts need another combination in Shortcut Studio. Unsupported/corrupt inputs report failure; do not repeatedly retry untrusted huge inputs. For support, export OS/runtime diagnostics from Privacy Center. Store/MSIX installation is not yet available.
## Brainiac Edge
Open Brainiac Edge from the dashboard, navigation or Command Center. Ctrl+Shift+E toggles it by default; change its chord from Edge Settings or Shortcut Studio. A conflicting chord reports failure and retains the prior registration. Hover a monitor edge for the configured dwell; automatic activation respects fullscreen/presentation state. Pointer reveal leaves keyboard focus with your current app. Clicking a control or using the shortcut allows deliberate keyboard interaction. Escape hides; Keep open overrides pointer auto-hide.

Add opens real text/code/note/HTTP-link, file and folder pinning. Drop files, images or text onto the shelf; drag pins out with Copy effects. Original files remain in place. Right-click or Shift+F10 opens preview/copy, floating card, edit title/tags/content/expiry, favourites, pin protection, OCR, Capture editor, Teleprompter, Shelf, PDF export, relink and removal actions. Select multiple pins with Ctrl/Shift for bulk metadata toggles, removal or combined PDF export. Enter opens; Ctrl+C copies a selected pin; Ctrl+F focuses search; Delete requests removal confirmation.

Search matches local word prefixes in titles, content, tags and OCR text. Use type/favourite filters and Recent (latest 50). All collections also exposes pins from deleted workspaces; newly added pins in that view go to General. Workspace creation/update/duplicate/import retains or creates stable IDs; opening a workspace selects its Edge collection. Choose Coding, Study, Research, Business or Presentation collections by creating those workspaces in the existing Workspaces tool.

Detached cards have native dragging/resizing, optional Always on top, opacity, Copy, Edit, pin protection, minimize and Close. Closing a card retains the pin. Detach the same pin again or restore minimized cards from Add. Geometry is saved locally; cards do not automatically reopen at startup. Office/PDF/file pins display type/path references and open with their installed native handler; images have thumbnails and full-image preview. Capture editor annotations export separately.

Settings offers dimensions, alignment, four dock edges, monitor selection, sensitivity, hover dwell, auto-hide, compact/expanded thumbnail sizes, translucency, reduced motion and fullscreen suppression. Automatic screenshots, offline OCR and OCR-to-Shelf are separately opt-in. Workflow Studio can pin reviewed file sources after successful execution, or run an image-to-pinboard/OCR/Shelf/PDF pipeline. These are explicit manual workflows; partial results remain if a later step fails.

Expiry removes only unpinned metadata, at startup/reveal or manual cleanup. File references that go missing remain available to relink. Backups merge pins transactionally and include managed captures; external files remain references. Backups are plain JSON, capped at 32 MB. Use a profile-folder backup for larger image collections. Restore does not launch links or files. Manual managed-image cleanup removes only unreferenced PNGs older than one day.

## Redesigned creative dashboard
Projects are the existing saved workspace collections: Create New Project opens the real workspace editor, where you name the collection and choose its tools. Continue working uses saved scripts and workspace collections. Saved Files uses the retained operation journal and reports missing originals. Global search covers actual commands, workspace names, script titles, saved output names and Edge text/OCR content. No account profile or invented productivity metrics are displayed.

New profiles start in light mode; saved Light/Dark preferences remain respected. Existing settings still persist in SQLite. The contextual dashboard column is hidden on narrower windows; core navigation, tools, search and recent activity remain accessible. Use sidebar categories to collapse tool groups.

Teleprompter settings now include alignment, reading text/background colours, a reading guide and vertical flip, alongside existing speed/font/opacity/mirroring, script library and voice follow. Full screen / restore is available from controls and Ctrl+Alt+F when registered. The independent reading surface keeps its chosen high-contrast colours in either application theme. Native Windows file pickers and confirmation dialogs follow Windows styling.
