Privacy policy BrainiacDeck Ultimate by FRANCIS KUSI / BrainiacTech Hub processes files locally. It has no analytics, advertisements, required account, remote database, cloud OCR or cloud AI. Core tools work offline after installation.

Local data under %LOCALAPPDATA%\BrainiacDesk includes a SQLite preference database, an optional conversion preset (including its output folder), workflow definitions with folder paths, workspace tool collections, shortcut preferences, command favorites, and at most 200 module-opening/completion activity events. These ordinary configuration files are not encrypted; do not put secrets in names or settings. An explicit BRAINIACDESK_DATA environment override can select another local profile for testing.

Clipboard monitoring starts off and requires a session-only consent checkbox. Manual clipboard reads require a button click. Shelf content stays in process memory, with a 50-item limit and one-hour expiry for unpinned items. Using Close tool on the shelf or exiting the app removes its monitoring registration. Navigating to another tool keeps the current shelf session available. Persistence starts off; if explicitly enabled, text/images/file references are saved using Windows account data protection and restored without re-enabling monitoring. Disabling persistence deletes the saved shelf. Protected archives have a 24 MB limit. Clipboard text filters are limited and cannot guarantee password detection: pause before copying private content. Other apps and Windows may maintain their own clipboard history.

Screenshots and annotations stay in memory until copied, exported, explicitly pinned to Edge, or saved by an enabled capture-to-Edge workflow. Undo may retain unredacted pixels in memory, while exports flatten opaque redaction. PDF screenshot export uses a temporary local image and deletes it afterward; this is not secure disk erasure. Scripts saved to the local library are protected with Windows account data protection; exported TXT files are unencrypted. Up to 200 actual operation results, including input/output paths and outcomes, are saved in a protected journal. Teleprompter geometry and display settings are ordinary preferences. Offline voice follow requests microphone consent each time it starts, uses an installed Windows recognizer, and does not save audio. Stop/close releases the microphone. Exported/conversion/workflow files remain in the chosen directories. No automatic user-file deletion or background workflow monitoring is implemented.

Privacy controls clear activity and operation history, delete saved scripts/shelf after their windows close, remove saved configurations, export preferences, and generate OS/runtime-only support diagnostics. They do not delete exported files, scripts or screenshots from external folders. There is no startup integration. Exit stops the process and its listeners.

Support and privacy questions: https://github.com/brainiacweb-tech/BrainiacDeck-Ultimate/issues. Issues are public; do not include private scripts, screenshots, passwords or personal files. This policy is available at https://github.com/brainiacweb-tech/BrainiacDeck-Ultimate/blob/main/PRIVACY.md. ## Brainiac Edge Edge does not register another clipboard listener or read the clipboard in the background. Pinning an existing Shelf item explicitly saves it to the local Edge collection; current Shelf text exclusions apply. Edge pins, tags, OCR text and settings are stored in additive tables in settings.db without Windows-account encryption. Managed images are saved under Edge/Images; original file/folder pins are references. Automatic capture pinning, capture OCR and recognized-text handoff to Shelf default off and can be enabled separately. Windows OCR uses installed local language packs and sends no content to external services.

Thumbnails are decoded asynchronously into a bounded memory cache. Local JSON backups contain pin text, paths and managed screenshot bytes without encryption; external files are not copied. Removing/expiring a pin never deletes original files. Expiry applies to unpinned entries on startup, on shelf reveal (at most once per minute), or through manual cleanup. Unreferenced Edge-owned PNGs older than one day can be manually removed from Edge Settings; no automatic deletion of external files is performed. Uninstall/profile cleanup remains subject to packaged acceptance testing.
